# Simple Lantern — порт на Minecraft 1.12.2

Исходный мод: **Simple Lantern** от FLUFFY2 (Forge 1.7.10).
Это перенос его логики на Forge 1.12.2. Код написан заново под новое API,
текстуры и звуки взяты из оригинального jar и переименованы в нижний регистр
(в 1.12.2 пути к ресурсам обязаны быть lowercase).

## Сборка (Windows)

Нужна **Java 8** и интернет (Gradle качает Forge, Minecraft и маппинги сам).

1. Открой папку проекта, зайди внутрь неё.
2. Запусти в командной строке:
   ```
   gradlew.bat build
   ```
3. Первый запуск займёт долго (5-15+ минут) — качается Gradle, Forge,
   ванильный Minecraft 1.12.2 и MCP-маппинги. Не прерывай процесс.
4. Готовый мод появится в `build/libs/SimpleLantern-1.1.0.jar`.

Проверить в игре:
```
gradlew.bat runClient
```
Запустит тестовый клиент с уже подключенным модом.

Если что-то упадёт с ошибкой — скопируй текст ошибки целиком и пришли,
поправим код и соберёшь заново.

## Что уже работает

- Конфиг (`config/SimpleLantern.cfg`) — теперь через аннотации `@Config`,
  с рабочим экраном настроек в меню модов и синхронизацией на клиент при входе.
- Предметы: `coal_fuel`, `lantern_off`, `lantern_on`.
- Зажжённый фонарь по-прежнему `ItemArmor` на слот ног (носится на поясе).
- Блоки `lantern_off` / `lantern_on` с `TileEntityLantern`, топливо хранится в TE.
- ПКМ — зажечь/потушить, шифт+ПКМ — сменить режим отражателя, по блоку шифт+ПКМ — забрать.
- Расход топлива у надетого фонаря и у фонарей в инвентаре, сообщение «Out of fuel!».
- Рецепты: фонарь и топливо — JSON (`assets/simplelantern/recipes/`),
  дозаправка — динамический `IRecipe` с возвратом пустых бутылок.
- Свои звуки через реестр `SoundEvent`.

## Что осталось доделать

1. **Кастомная 3D-модель фонаря.** В оригинале были Techne-модели
   (`ModelSimpleLantern1/2`) плюс `TileEntityLanternRenderer`, `ItemLanternRenderer`
   и `LanternBeltRender`. Здесь вместо них простые JSON-модели: блок — параллелепипед
   6x11x6, предмет — плоская иконка. Если нужна прежняя 3D-модель, её надо перенести
   отдельно: `TileEntitySpecialRenderer` в 1.12.2 живой, рендер брони — через
   `ModelBiped` из `getArmorModel`.
2. **Динамический свет от надетого фонаря.** В 1.7.10 он делался через
   `IExtendedEntityProperties` (сохранялись `lastPlayerX/Y/Z` и результат raytrace) —
   скорее всего расстановкой невидимых блоков света. `IExtendedEntityProperties`
   в 1.12.2 удалён, замена — Capabilities. Проще подключить готовый
   динамический свет (Albedo / LLibrary) вместо переписывания.
3. **NEI → JEI.** `NEIAmnesiaLightsConfig` не переносился: NEI под 1.12.2 нет,
   аналог — JEI (`IModPlugin`, скрытие предметов через `IJeiRuntime`).
4. **Генерация в сундуках.** `ChestGenHooks` удалён. В 1.12.2 это JSON-таблицы
   лута плюс `LootTableLoadEvent` — надо будет добавить, если нужно.
5. **Рецепт фонаря** я собрал по ингредиентам из старого кода (палка, стекло,
   булыжник) — проверь раскладку и поправь `recipes/lantern_off.json` под оригинал.

## Важно

Проект не компилировался: здесь нет доступа к сети, а ForgeGradle качает
Forge и маппинги при первом запуске. Мелкие правки сигнатур при первой сборке
возможны — пиши, что именно ругается, разберём.

Мод авторства FLUFFY2. Для личного использования порт делать можно,
для публикации нужно разрешение автора.
